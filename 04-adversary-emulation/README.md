# Adversary Emulation

This category contains safe, controlled test activity used to validate telemetry and detections without deploying real malware.

## Project

### Safe Adversary Emulation and ATT&CK-Aligned Detection Testing

The project provides:

- Rules of engagement and authorized-asset boundaries.
- VirtualBox snapshot and recovery procedures.
- Eight repeatable test cases.
- MITRE ATT&CK technique mapping.
- Expected-versus-actual telemetry matrices.
- Evidence across endpoint, EDR, SIEM, network, web, IDS, and firewall layers.
- Cleanup validation and troubleshooting records.
- A capability matrix for reuse in the next purple-team phase.

# Prohibited Actions

- Running tests on the physical host.
- Targeting systems outside the owned lab.
- Bridging adversary-emulation traffic to the real LAN.
- Using real malware, ransomware, persistence, credential theft, exfiltration, or destructive commands.
- Disabling security controls globally to make a test pass.
- Uploading EICAR contents, executable artifacts, credentials, tokens, private keys, VM disks, or raw sensitive logs to GitHub.
- Claiming a detection passed without supporting evidence.
